Lightweight administrator addition for servers that lets you set specific players to be completely invincible to any damage, with zero impact on server performance.

## Features
- **True Invincibility**: Intercepts and negates all damage causes (PvP, mobs, fall, kinetic, fire, lava, drowning, suffocation, explosions, hunger, and `/kill`).
- **Zero Lag**: Runs completely in memory so it never slows down your server or drops TPS.
- **Works Offline**: You can toggle godmode for players even when they aren't on the server.
- **Thorns Retribution**: Launches attackers flying backwards and strikes them back (customizable in config).
- **Safe Auto-Saving**: Automatically saves in the background so you never lose data, even if the server crashes.

## Commands & Permissions
- `/godmode <player>` — Toggle godmode for an online or offline player.
- Permission: `godmode.admin` (defaults to OP).
